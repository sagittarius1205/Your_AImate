# 나만의 데스크톱 어시스턴트 만들기

AImate의 캐릭터는 폴더 하나입니다. 폴더에는 레이어 PNG, `layers.json`(어떤 레이어가 있고 각각 어디에 놓이는지), `rig.json`(각 레이어가 어떻게 움직이는지), `character.json`(캐릭터가 누구이고 어떻게 말하는지)이 들어 있으며, 캐릭터 고유의 목소리도 넣을 수 있습니다. 폴더를 캐릭터 폴더에 넣고 데스크톱 펫을 다시 시작하면 설정에서 그 캐릭터로 바꿀 수 있으며, 다시 빌드할 필요는 없습니다.

앱의 화면은 번체 중국어로만 되어 있습니다. 이 문서에서는 눌러야 하거나 찾아야 하는 버튼, 탭, 항목 이름을 앱에 표시되는 중국어 그대로 적고, 괄호 안에 한국어 뜻을 붙였습니다.

샤오커(小克)는 기본 캐릭터입니다. 얼마나 바꾸고 싶은지에 따라 아래에서 길을 하나 고르세요.

| 바꾸고 싶은 것 | 볼 절 | 필요한 것 |
| --- | --- | --- |
| 이름, 성격, 첫인사, 말버릇 | 1절 | 아무것도 설치할 필요 없음 |
| 다른 그림으로 바꾸기 | 2절에서 6절까지 | 그림을 편집할 수 있는 AI, Python |
| 목소리 바꾸기, 말버릇을 캐릭터의 목소리로 | 7절 | 로컬 음성(README 설치의 3단계) |
| 인터페이스의 색과 둥근 모서리 | 9절 | 아무것도 설치할 필요 없음 |

아래 명령은 모두 PowerShell에서 repo 루트 디렉터리를 기준으로 실행합니다. `%USERPROFILE%\.vrpet`은 데스크톱 펫의 폴더입니다. 환경 변수 `VRPET_HOME`을 설정했다면 그 위치가 됩니다.

## 1. 성격만 바꾸기: 샤오커를 복사하기

1. 캐릭터 옆의 **設定**(설정)을 눌러 **角色**(캐릭터) 탭을 엽니다.
2. 샤오커는 내장 캐릭터라서 직접 고칠 수 없습니다. **複製到我的資料夾**(내 폴더로 복사) 왼쪽 칸에 새 폴더 이름(예: `my-xiaoke`)을 입력하고 버튼을 누릅니다.
3. 데스크톱 펫이 복사된 사본으로 바뀝니다. **名字**(이름), **服裝**(의상), **個性**(성격), **開場白**(첫인사), **口頭禪**(말버릇)을 고치고 **存檔**(저장)을 누릅니다. 저장하면 캐릭터가 곧바로 새 설정으로 바뀌며, 다시 시작할 필요가 없습니다.

**個性**(성격)은 Claude에게 주는 캐릭터 설명이며, 최대 2000자입니다. 고정된 규칙(캐릭터가 듣고 말할 수 있다는 것, 손짓하는 방법)은 프로그램이 채워 넣으므로, 여기에는 캐릭터가 누구이고 어떻게 말하는지만 쓰면 됩니다.

복사된 폴더는 `%USERPROFILE%\.vrpet\characters\my-xiaoke\`에 있으며, 샤오커의 레이어, `layers.json`, `rig.json`, `character.json`이 들어 있습니다. 나중에 그림이나 목소리를 바꿀 때 이 폴더에서 시작하면 됩니다.

## 2. 그림 다섯 장 준비하기

레이어 분리 스크립트는 전신 일러스트 한 장을 움직일 수 있는 레이어 22개로 나눕니다. 예를 들면 뒷머리, 얼굴, 양쪽 눈 각각의 흰자, 홍채, 속눈썹, 감은 눈, 벌린 입, 앞머리입니다. 이 스크립트에는 같은 그림의 다섯 가지 버전이 필요하며, 모두 같은 작업 폴더에 넣어야 합니다.

| 파일 | 내용 | 이미지 편집 AI에게 줄 지시문 |
| --- | --- | --- |
| `master.png` | 마스터: 배경을 순수 마젠타 `#FF00FF`로 바꾸고, 글로우를 없애고, 입은 다물고 눈은 뜬 상태 | `brief_master.md` |
| `partmap.png` | 부위 색 영역 맵: 각 부위를 단색 하나로 칠한 그림으로, 레이어를 나눌 때 마스크로 씁니다 | `brief_partmap.md` |
| `nofront.png` | 앞머리를 모두 없애고, 이마와 머리카락에 가려진 옷을 채워 넣은 그림 | `brief_nofront.md` |
| `backhair.png` | 뒷머리만 남기고, 머리와 몸에 가려진 부분을 완전하게 채운 그림 | `brief_backhair.md` |
| `face_states.png` | 눈을 감고 입을 벌린 그림 | `brief_face.md` |

이 다섯 지시문은 `Scripts/live2d/`에 있으며, 그림을 편집할 수 있는 AI에게 주는 영어 프롬프트입니다. 샤오커의 다섯 장은 ChatGPT의 이미지 편집 기능으로 만들었습니다.

1. 원본 그림을 `source.png`로 저장해 작업 폴더(예: `%USERPROFILE%\aimate-art\hana\`)에 넣습니다. 원본은 정면을 보고 똑바로 선 전신 그림이어야 하며, 두 팔은 몸에서 조금 떨어지고 두 다리는 벌어져 있어야 합니다. 샤오커의 원본은 1024×1536 세로 그림입니다.
2. `brief_master.md`에는 샤오커의 외모(머리카락, 태양 머리핀, 재킷, 주름치마, 부츠)를 설명하는 항목이 하나 있습니다. 먼저 이 항목을 여러분의 캐릭터에 맞게 고치세요.
3. `master.png`를 먼저 만듭니다. 나머지 네 장은 모두 `master.png`를 입력 이미지로 삼아 편집하며, 동시에 만들어도 됩니다.
4. 모든 장은 "입력 이미지를 편집"해서 만들어야 하며, AI가 새로 그리게 하면 안 됩니다. 보이는 픽셀은 모두 마스터에서 가져오고 나머지 네 장은 가려진 곳과 변하는 부위만 채우므로, 그림이 몇 픽셀만 어긋나도 레이어가 맞지 않습니다.

색 영역 맵은 13가지 색을 쓰며, 대응표는 `brief_partmap.md`에 있습니다. 캐릭터에 어떤 부위가 없다면(예: 머리 장식이 없는 경우) 색 영역 맵에 그 색이 나타나지 않게 하세요.

## 3. 레이어 나누기

처음에는 먼저 Python 패키지를 설치합니다.

```powershell
uv venv --python 3.11 .venv-art
uv pip install --python .venv-art\Scripts\python.exe psd-tools numpy pillow opencv-python-headless scipy
```

그다음 레이어를 나눕니다. 마지막 줄 `layers.py`의 두 번째 인자는 캐릭터 폴더이며, 폴더 이름 `hana`가 곧 캐릭터의 id입니다(규칙은 6절 참고).

```powershell
$work = "$env:USERPROFILE\aimate-art\hana"
.venv-art\Scripts\python.exe Scripts\live2d\cut.py $work
.venv-art\Scripts\python.exe Scripts\live2d\layers.py $work "$env:USERPROFILE\.vrpet\characters\hana"
```

`cut.py`는 배경을 제거하고, 색 영역 맵과 마스터가 서로 맞는지 확인합니다. 출력되는 두 숫자가 샤오커의 경우 `silhouette IoU 0.9868`과 `mean 0.64 px`입니다. IoU가 0.98보다 뚜렷하게 낮거나 평균 오차가 몇 픽셀이나 된다면 색 영역 맵이 다시 그려졌거나 움직였다는 뜻이므로, 새로 만들어야 합니다.

`layers.py`는 레이어 PNG와 `layers.json`을 캐릭터 폴더에 쓰고, 작업 폴더에 `character.psd`와 `rest_stack.png`를 남깁니다. 다음 줄들을 확인하세요.

- `shift nofront … backhair … face_states …`: 보정 그림 세 장이 마스터에서 어긋난 정도입니다. 샤오커는 모두 0.2 px 이내입니다. 1 px를 넘으면 그 그림이 움직였다는 뜻입니다.
- `rest stack vs master: mean abs error`: 모든 레이어를 정지 상태로 겹쳤을 때 마스터와 얼마나 다른지입니다. 샤오커는 0.59/255입니다.
- `hair_clip is empty and left out; remove it from rig.json's layers`: 이 그림에는 해당 부위가 없어서 그 레이어도 없습니다. 다음 단계에서 `rig.json`에서 그것을 빼야 합니다.

그리고 `rest_stack.png`를 열어 한번 보세요. 모든 레이어를 정지 상태로 겹친 모습이며, 마스터와 똑같아 보여야 합니다.

눈을 나누는 색 기준값은 샤오커의 그림에 맞춰 정한 것입니다. 다른 얼굴로 바꾸면 흰자, 홍채, 속눈썹이 잘못 나뉠 수 있습니다. 예를 들어 흰자가 가는 틈만 남으면 데스크톱 펫에서 홍채가 잘려 보입니다. 같은 얼굴에서 만든 두 번째 의상은 `Scripts\live2d\reuse_eyes.py`로 첫 번째 의상에서 나눈 눈을 그대로 쓸 수 있으며, 사용법은 파일 첫머리에 적혀 있습니다.

## 4. `rig.json` 작성하기: 레이어 움직이기

샤오커의 `Pet\ui\characters\char-20261107\rig.json`을 캐릭터 폴더로 복사합니다. 1절에서 복사한 폴더에는 이미 이 파일이 있습니다.

**`parameters`는 한 글자도 바꾸지 마세요.** 고개 끄덕임과 손짓의 동작 수치(`Pet/src-tauri/src/cue/figure.json`)는 이 매개변수 표에 묶여 있습니다. 각 매개변수의 id, 범위, 기본값, 그리고 그 순서까지입니다. 완전히 같으면 새 캐릭터도 샤오커와 똑같이 고개를 끄덕이고 손짓을 합니다. 조금이라도 바꾸면 손짓이 모두 꺼지고, 대기 동작, 눈 깜빡임, 입 모양, 커서 바라보기만 남습니다.

바꿔야 할 것은 회전축(피벗)입니다. 즉 샤오커 몸의 위치를 여러분 캐릭터 몸의 같은 위치로 바꾸는 것입니다. 좌표는 `layers.json`의 `canvas` 위 픽셀, 곧 `master.png`의 픽셀이며, 왼쪽 위가 (0, 0)입니다. 커서 좌표가 보이는 이미지 뷰어나 그림 프로그램이라면 무엇으로든 잴 수 있습니다.

| `rig.json`의 위치 | 무엇인가 | 샤오커의 값 |
| --- | --- | --- |
| `nodes`의 `body` | 허리, 몸이 흔들리는 중심 | `[510, 600]` |
| `nodes`의 `skirt` | 치마가 흔들리는 중심 | `[510, 590]` |
| `nodes`의 `head` | 목, 머리가 돌아가는 중심 | `[507, 270]` |
| `nodes`의 `armRight` | 화면 왼쪽 팔의 어깨 | `[385, 335]` |
| `nodes`의 `armLeft` | 화면 오른쪽 팔의 어깨 | `[638, 335]` |
| `layers`의 `back_hair` | 뒷머리가 흔들리는 받침점, 정수리에 있음 | `[512, 40]` |
| `layers`의 `front_hair`, `hair_clip` | 앞머리가 흔들리는 받침점 | `[505, 20]` |
| `layers`의 `eye_white_image_left`, `iris_image_left`, `eye_lash_image_left` | 화면 왼쪽 눈의 중심 | `[462, 169]` |
| `layers`의 `eye_white_image_right`, `iris_image_right`, `eye_lash_image_right` | 화면 오른쪽 눈의 중심 | `[557, 167.5]` |
| `layers`의 `mouth_open` | 입의 중심, 입을 벌릴 때 여기서 위아래로 벌어짐 | `[508, 224]` |
| `layers`의 `leg_image_left`, `leg_image_right` | 허벅지 바깥쪽의 위 가장자리, 두 다리를 모을 때의 회전축 | `[352, 866]`, `[666, 862]` |
| `look`의 `at` | 두 눈 사이, 커서를 바라볼 때 여기서 봄 | `[508, 170]` |

눈의 중심은 `layers.py`가 출력하는 `iris left: centre x,y`와 `iris right: centre x,y`를 그대로 쓰면 됩니다.

레이어 이름의 left와 right는 화면의 좌우입니다. 노드 이름은 캐릭터 자신의 좌우이므로, `armRight` 노드에 달린 것은 `arm_image_left`, 즉 화면 왼쪽 팔입니다.

각 `drive`에는 "이 매개변수 한 단위마다 `x`/`y` 픽셀만큼 이동, `rotate`도만큼 회전, `sx`/`sy`만큼 확대 또는 축소"가 적혀 있습니다. 팔은 한 단위가 1도입니다. 처음에는 고치지 말고, 바탕 화면에서 움직이는 모습을 본 뒤 조정하세요.

`layers.py`가 뺀 레이어는 `rig.json`의 `layers`에서도 그 항목을 지워야 합니다. 지우지 않으면 캐릭터가 그려지지 않으며, 그 이유는 `rig.json rigs hair_clip, which layers.json does not have`입니다.

각 레이어는 한 장짜리라서 이동, 회전, 확대 또는 축소만 할 수 있고, Live2D처럼 변형되지는 않습니다. 눈 깜빡임과 입 벌리기는 그림 두 장 사이를 전환하는 방식입니다.

## 5. `character.json` 작성하기

```json
{
  "name": "하나",
  "outfit": "유니폼",
  "persona": "당신은 사용자의 바탕 화면 한쪽에 살고 있습니다. 짧고 친절하게 말하며, 한국어로 대답합니다.",
  "greeting": "안녕하세요, 저는 하나예요.",
  "voice": "voice.wav",
  "fillers": ["음……", "생각해 볼게요"]
}
```

| 항목 | 필수 | 제한 | 쓰이는 곳 |
| --- | --- | --- | --- |
| `name` | 예 | 1자에서 32자까지, 줄바꿈 불가 | 설정 목록, 대화창의 이름표, Claude에게 주는 설명 |
| `persona` | 예 | 1자에서 2000자까지 | Claude에게 주는 캐릭터 설명 |
| `outfit` | 아니요 | 1자에서 16자까지, 줄바꿈과 대괄호 불가 | 설정 목록에만 "하나（유니폼）"처럼 표시되며, 같은 캐릭터의 다른 옷을 구분하는 데 씁니다 |
| `greeting` | 아니요 | 최대 200자, 대괄호 불가 | 데스크톱 펫이 시작할 때와 이 캐릭터로 바꿀 때 한 번 말합니다 |
| `voice` | 아니요 | `"voice.wav"`만 쓸 수 있으며, 폴더에 이 파일이 실제로 있어야 합니다 | 캐릭터의 목소리. 7절 참고 |
| `fillers` | 아니요 | 최대 12문장, 문장마다 1자에서 40자까지 | 캐릭터가 답을 생각할 때 말하는 말버릇. 7절 참고 |

알 수 없는 항목은 거부됩니다. 항목 이름을 잘못 쓰면 설정 목록에 어떤 항목인지 바로 표시되며, 아무 표시 없이 효과만 사라지는 일은 없습니다.

## 6. 폴더를 넣고 그 캐릭터로 바꾸기

1. 폴더 이름이 곧 캐릭터의 id입니다. 영문 소문자, 숫자, `-`, `_`만 쓸 수 있고, 첫 글자는 영문자나 숫자여야 하며, 최대 48자입니다. 내장 캐릭터와 같은 이름은 쓸 수 없습니다.
2. 폴더는 `%USERPROFILE%\.vrpet\characters\<id>\`에 둡니다. **設定**(설정)의 **角色**(캐릭터) 탭에 있는 **打開角色資料夾**(캐릭터 폴더 열기)를 누르면 이곳이 바로 열립니다.
3. 폴더 최상위에 `character.json`, `rig.json`, `layers.json`, 그리고 `layers.json`에 나열된 모든 PNG가 있는지 확인합니다.
4. **結束**(종료)를 눌러 데스크톱 펫을 닫고, `Scripts\start_pet.ps1`을 다시 실행합니다.
5. **設定**(설정)의 **角色**(캐릭터) 탭을 열고 캐릭터의 이름을 클릭합니다.

데스크톱 펫은 여러분의 선택을 기억하므로, 다음에 켤 때도 그 캐릭터가 나옵니다.

## 7. 캐릭터의 목소리와 말버릇

이 절에는 로컬 음성이 필요합니다. 로컬 음성을 설치하지 않아도 캐릭터는 쓸 수 있으며, 소리만 나지 않습니다.

**목소리.** 참고 녹음 하나를 `voice.wav`로 저장해 캐릭터 폴더에 넣고, `character.json`에 `"voice": "voice.wav"`를 추가한 뒤 데스크톱 펫을 다시 시작합니다. 음성 서비스가 이 녹음의 목소리를 흉내 내며, 대본은 필요 없습니다.

- 한 사람의 깨끗한 녹음을 쓰세요. 배경 음악과 잡음이 없어야 합니다. 샤오커의 참고 녹음은 22.7초입니다.
- 녹음의 음질도 함께 흉내 냅니다. 전화 음질의 녹음이면 합성 결과도 전화처럼 들립니다.
- 파일은 최대 10 MB입니다.
- 사용할 권리가 있는 목소리만 쓰세요. 본인의 동의 없이 실제 사람의 목소리를 흉내 내지 마세요.

**말버릇.** 캐릭터는 답을 생각할 때 먼저 말버릇 한마디를 합니다. `character.json`에 `fillers`를 적은 뒤, 음성 서비스가 켜져 있고 캐릭터 폴더가 제자리에 있을 때 다음을 실행합니다.

```powershell
.venv\Scripts\python.exe Scripts\tts_engines\render_fillers.py "$env:USERPROFILE\.vrpet\characters\hana"
```

이 스크립트는 캐릭터의 목소리로 각 문장을 두 번씩 합성해 더 나은 쪽을 남기고, 그 결과를 `fillers.json`으로 씁니다. 결과는 음성 인식으로 검사하지 않았으므로 직접 한 번 들어 보세요.

캐릭터에게 자기 목소리가 있는데 `fillers.json`이 없으면 말버릇을 하지 않습니다. 기본 말버릇 세트는 샤오커의 목소리이기 때문입니다.

## 8. 캐릭터가 나타나지 않거나 모습이 이상할 때

| 보이는 증상 | 원인 | 해결 방법 |
| --- | --- | --- |
| 설정 목록에서 그 캐릭터의 줄이 회색으로 비활성화되고, 뒤에 이유가 적혀 있음 | 스캔할 때 검사를 통과하지 못함 | 적힌 이유대로 고치고 데스크톱 펫을 다시 시작 |
| 목록에 아예 없음 | 폴더가 `characters` 안에 없거나, 아직 다시 시작하지 않음 | **打開角色資料夾**(캐릭터 폴더 열기)로 위치 확인 |
| 캐릭터가 그려지지 않음 | `rig.json`과 레이어가 맞지 않음 | `%USERPROFILE%\.vrpet\logs\pet.log`에서 `SPIKE_REPORT` 줄의 `"character"`를 보면 `"error"`에 이유가 적혀 있음 |
| 고개 끄덕임과 손짓이 없음 | `rig.json`의 `parameters`가 샤오커의 것과 다름 | `pet.log`에 `gestures: <id> bound by cue/figure.json`이 있어야 연결된 것 |
| 글자는 나오는데 소리가 없음 | 대화창에 이유가 적힘 | 흔한 경우는 `character 'hana' has no voice.wav` |

회색으로 비활성화되는 흔한 이유:

- 폴더 이름이 규칙에 맞지 않음. 예를 들어 대문자나 공백이 있음.
- `character.json`, `rig.json`, `layers.json` 중 하나가 없음.
- `character.json`을 읽을 수 없음. 항목 이름을 잘못 쓰면 이유에 `unknown field`와 잘못 쓴 이름이 나옵니다.
- `voice`에 `voice.wav`를 적었는데 폴더에 그 파일이 없음.
- 파일이 너무 큼. 상한은 PNG 한 장당 16 MB, JSON 한 개당 1 MB(`fillers.json`은 8 MB), `voice.wav` 10 MB, 폴더 전체 200 MB입니다.
- 폴더 안에 바로 가기(symlink 또는 junction)가 있음. 데스크톱 펫은 안전을 위해 바로 가기를 따라가지 않으며, 그 캐릭터 전체를 불러오지 않습니다.

캐릭터 폴더는 다른 사람이 만들었거나 인터넷에서 내려받은 것일 수 있으므로, 데스크톱 펫은 폴더 최상위의 PNG, JSON, WAV만 읽고 모든 파일의 크기를 확인합니다. **個性**(성격)의 글은 Claude에게 전달되지만, 대화 코어의 Claude에는 도구가 전혀 없어서 여러분의 파일에 접근할 수 없습니다.

## 9. 인터페이스 테마

대화창의 색, 둥근 모서리, 작은 그림 두 장도 바꿀 수 있습니다. 방법은 캐릭터와 같습니다. 테마 하나는 폴더 하나이며, 그 안에 `theme.json`이 있습니다. 기본 테마는 **紙本**(종이, `paper`)과 **夜色**(밤, `night`) 두 가지입니다.

```json
{
  "name": "나의 테마",
  "colors": {
    "accent": "#d97757",
    "paper": "#f3f2ef",
    "ink": "#2b2b2b",
    "border": "#cfc8bc",
    "controls": "#f3f2ef"
  },
  "radius": 18,
  "icon": "icon.svg",
  "paper_texture": "paper.svg"
}
```

| 항목 | 필수 | 제한 | 쓰이는 곳 |
| --- | --- | --- | --- |
| `name` | 예 | 1자에서 32자까지 | **設定**(설정)의 **外觀**(외관) 탭 |
| `colors.accent` | 예 | `#rrggbb` | 마우스를 올렸을 때와 입력할 때의 테두리. 캐릭터의 이름은 accent를 ink 쪽으로 40% 옮긴 색 |
| `colors.paper` | 예 | `#rrggbb` | 대화창, 선택지, 대화 기록의 바탕색 |
| `colors.ink` | 예 | `#rrggbb` | 글자 색 |
| `colors.border` | 예 | `#rrggbb` | 모든 테두리 |
| `colors.controls` | 예 | `#rrggbb` | 버튼 줄, 입력창, 마이크 버튼의 바탕색 |
| `radius` | 예 | 0에서 28까지의 정수, 단위 px | 대화창의 둥근 모서리 |
| `icon` | 아니요 | 폴더 안의 `.svg` 또는 `.png` 파일 하나 | 대화창에서 캐릭터 이름 옆의 작은 아이콘 |
| `paper_texture` | 아니요 | 폴더 안의 `.svg` 또는 `.png` 파일 하나 | 바탕색 위에 까는 질감 |

1. 폴더 이름 규칙은 캐릭터와 같습니다. `%USERPROFILE%\.vrpet\themes\<id>\`에 두며, **設定**(설정)의 **外觀**(외관) 탭에 있는 **打開主題資料夾**(테마 폴더 열기)를 누르면 이곳이 열립니다.
2. 설정 창으로 돌아가면 새 테마가 목록에 있으며, 데스크톱 펫을 다시 시작할 필요는 없습니다. 클릭하면 바로 바뀝니다.

제한:

- 그림 파일 이름에는 영문 소문자, 숫자, `_`, `.`, `-`만 쓸 수 있습니다.
- `theme.json`은 최대 64 KB, 그림은 한 장당 최대 2 MB, 폴더 전체는 최대 8 MB입니다.
- 테마에는 CSS를 넣을 수 없으며, 위의 색 다섯 가지, 둥근 모서리, 그림 두 장만 바꿀 수 있습니다.
- 문제가 있는 테마는 회색으로 비활성화되고 이유가 표시됩니다. 선택한 테마가 망가지면 데스크톱 펫은 일단 **紙本**(종이)을 쓰고, 테마를 고치면 다시 그 테마로 돌아옵니다.

## 10. 캐릭터를 설치 패키지에 넣기

이 절은 repo 자체를 고치려는 사람을 위한 것입니다. 캐릭터 폴더를 `Pet/ui/characters/<id>/`에 넣고, `Pet/ui/characters/index.json`의 `characters`에 id를 추가한 뒤 데스크톱 펫을 다시 빌드합니다. 테마는 `Pet/ui/themes/<id>/`와 `Pet/ui/themes/index.json`입니다. 수정을 마치면 `Scripts\run_pet_selftests.ps1`을 한 번 실행하세요.
