# 自分だけのデスクトップアシスタントを作る

AImate のキャラクターは 1 つのフォルダです。フォルダには、レイヤーの PNG、`layers.json`（どんなレイヤーがあり、それぞれどこに置くか）、`rig.json`（各レイヤーがどう動くか）、`character.json`（彼女が誰で、どう話すか）が入っていて、彼女自身の声を入れることもできます。このフォルダをキャラクターフォルダに置いてデスクトップマスコットを再起動すれば、設定でそのキャラクターに切り替えられます。ビルドし直す必要はありません。

アプリの画面は繁体字中国語のみです。このガイドでは、ボタンや項目の名前を画面の表記のまま書き、後ろに日本語訳を括弧で添えています。

小克（シャオクー）はデフォルトのキャラクターです。どこまで変えたいかに合わせて、下の表から進み方を選んでください。

| 変えたいもの | 読む節 | 必要なもの |
| --- | --- | --- |
| 名前、性格、あいさつ、口ぐせ | 第 1 節 | 何もインストール不要 |
| 別の画像に替える | 第 2 節から第 6 節 | 画像を編集できる AI、Python |
| 声を替える、口ぐせを彼女の声にする | 第 7 節 | ローカル音声（README のインストールの手順 3） |
| 画面の色と角の丸み | 第 9 節 | 何もインストール不要 |

以下のコマンドはすべて PowerShell で、repo のルートディレクトリから実行します。`%USERPROFILE%\.vrpet` はマスコットのデータフォルダです。環境変数 `VRPET_HOME` を設定している場合は、その場所になります。

## 1. 性格だけ変える：小克をコピーする

1. キャラクターの横にある「設定」（設定）を押し、「角色」（キャラクター）タブを開きます。
2. 小克は内蔵キャラクターなので、直接は変更できません。「複製到我的資料夾」（自分のフォルダにコピー）の左にある欄に新しいフォルダ名（例：`my-xiaoke`）を入力してから、ボタンを押します。
3. マスコットはコピーされた方に切り替わります。「名字」（名前）「服裝」（衣装）「個性」（性格）「開場白」（あいさつ）「口頭禪」（口ぐせ）を書き換えて、「存檔」（保存）を押します。保存するとすぐに新しい設定に切り替わり、再起動は不要です。

「個性」（性格）は会話モデルに渡すキャラクター説明で、最大 2000 文字です。決まったルール（彼女は聞くことも話すこともできる、身ぶりをどうするか）はプログラムが補うので、ここには彼女が誰で、どう話すかだけを書けば十分です。

コピーされたフォルダは `%USERPROFILE%\.vrpet\characters\my-xiaoke\` にあり、中には小克のレイヤー、`layers.json`、`rig.json`、`character.json` が入っています。あとで画像や声を替えるときは、このフォルダから手を加えていけます。

## 2. 5 枚の画像を用意する

切り分けスクリプトは、1 枚の全身立ち絵を 22 個の動かせるレイヤーに切り分けます。たとえば後ろ髪、顔、左右それぞれの目の白目・虹彩・まつ毛、閉じた目、開いた口、前髪などです。そのために同じ画像の 5 つのバージョンが必要で、すべて同じ作業フォルダに置きます。

| ファイル | 内容 | 画像編集 AI への指示 |
| --- | --- | --- |
| `master.png` | マスター：背景を純マゼンタ `#FF00FF` にし、光のにじみを取り除き、口を閉じて目を開けた状態 | `brief_master.md` |
| `partmap.png` | パーツ色分け図：パーツごとに 1 色の純色で塗り、切り分け用のマスクとして使う | `brief_partmap.md` |
| `nofront.png` | 前髪をすべて取り除き、額と、髪に隠れていた服を描き足したもの | `brief_nofront.md` |
| `backhair.png` | 後ろ髪だけを残し、頭と体に隠れていた部分を描き足して完成させたもの | `brief_backhair.md` |
| `face_states.png` | 目を閉じて口を開けた状態 | `brief_face.md` |

この 5 つの指示は `Scripts/live2d/` にあり、画像を編集できる AI 向けの英語のプロンプトです。小克の 5 枚は ChatGPT の画像編集機能で作りました。目の色分け図には別に `brief_eyemap.md` があり、第 3 節で使います。

1. 元の画像を `source.png` として保存し、作業フォルダ（例：`%USERPROFILE%\aimate-art\hana\`）に置きます。元の画像は正面向きで直立した全身画像にし、両手を体から少し離し、両足を開いた姿勢にします。小克の元画像は 1024×1536 の縦長の画像です。
2. `brief_master.md` には小克の外見（髪、太陽のヘアクリップ、上着、プリーツスカート、ブーツ）を説明している項目が 1 つあります。まずこの項目を自分のキャラクターに合わせて書き換えます。
3. 最初に `master.png` を作ります。残りの 4 枚はどれも `master.png` を入力画像として編集するので、同時に作業できます。
4. どの画像も「入力画像を編集する」形で作り、AI に描き直させないでください。見えているピクセルはすべてマスターから取り、他の 4 枚は隠れていた部分と変化する部位だけを補います。そのため画像が数ピクセルずれるだけで、レイヤーが揃わなくなります。

色分け図は 13 色を使い、対応表は `brief_partmap.md` にあります。キャラクターにないパーツ（たとえば髪飾りがない場合）は、その色を色分け図に入れないでください。

## 3. レイヤーに切り分ける

初回は、まず Python パッケージをインストールします。

```powershell
uv venv --python 3.11 .venv-art
uv pip install --python .venv-art\Scripts\python.exe psd-tools numpy pillow opencv-python-headless scipy
```

次に切り分けます。最後の行の `layers.py` の 2 番目の引数はキャラクターフォルダで、フォルダ名の `hana` がキャラクターの id になります（ルールは第 6 節を参照）。

```powershell
$work = "$env:USERPROFILE\aimate-art\hana"
.venv-art\Scripts\python.exe Scripts\live2d\cut.py $work
.venv-art\Scripts\python.exe Scripts\live2d\layers.py $work "$env:USERPROFILE\.vrpet\characters\hana"
```

`cut.py` は背景を取り除き、色分け図とマスターがきちんと重なるかを確認します。表示される 2 つの数値は、小克の場合 `silhouette IoU 0.9868` と `mean 0.64 px` です。IoU が 0.98 より明らかに低い、または平均誤差が数ピクセルある場合は、色分け図が描き直されたか動かされています。作り直してください。

`layers.py` はレイヤーの PNG と `layers.json` をキャラクターフォルダに書き出し、作業フォルダには `character.psd` と `rest_stack.png` を残します。次の行を確認してください。

- `shift nofront … backhair … face_states …`：補った 3 枚の画像のマスターに対するずれです。小克ではどれも 0.2 px 以内です。1 px を超える場合は、その画像が動かされています。
- `rest stack vs master: mean abs error`：静止状態の全レイヤーを重ねたものが、マスターとどれだけ違うかです。小克は 0.59/255 です。
- `hair_clip is empty and left out; remove it from rig.json's layers`：この画像にはこのパーツがないので、このレイヤーはありません。次の手順で `rig.json` から取り除きます。

さらに `rest_stack.png` を開いて確認してください。これは静止状態の全レイヤーを重ねた姿で、マスターと同じに見えるはずです。

目を分けるための色のしきい値は、小克の画像に合わせて決めてあり、虹彩として探すのは彼女の明るいオレンジ色です。別の顔にすると、白目・虹彩・まつ毛がうまく分かれないことがあります。たとえば白目が細い線しか残らないと、マスコット上で虹彩が切れてしまいます。虹彩がオレンジ色でない場合、`layers.py` は虹彩を見つけられず、エラーを表示して途中で止まることがあります。同じ顔から作った 2 着目の衣装では、`Scripts\live2d\reuse_eyes.py` を使って 1 着目で分けた目をそのまま流用できます。使い方はファイルの先頭に書いてあります。

目がうまく分かれないときや `layers.py` が止まったときは、目の色分け図をもう 1 枚作り、`layers.py` にそれを使って目を分けさせます：

1. `.venv-art\Scripts\python.exe Scripts\live2d\eyemap.py crop $work` を実行します。`partmap.png` で両目の位置を見つけ、`master.png` から両目を切り出し、1536×1024 の `eyes_crop.png` に拡大します。切り出した位置は `eyes_crop.json` に記録します。
2. `eyes_crop.png` と `brief_eyemap.md` を画像を編集できる AI に渡します。ほかの画像と同じく、`eyes_crop.png` を編集させ、描き直させないでください。この指示は 4 色だけを使うよう求めています。白目はシアン `#00FFFF`、虹彩は青 `#0000FF`、まつ毛とまぶたの線は黒 `#000000`、それ以外はすべてマゼンタ `#FF00FF` です。
3. 結果を `eyes_map.png` として作業フォルダに保存し、`.venv-art\Scripts\python.exe Scripts\live2d\eyemap.py paste $work` を実行します。`eyes_map.png` を両目の元の位置と大きさに戻し、`eyemap.png` として保存します。
4. 上と同じコマンドで `layers.py` をもう一度実行します。

作業フォルダに `eyemap.png` があると、`layers.py` は毎回それを使って目を分け、`eyes from eyemap.png: white … px, iris … px, lashes … px` という行を 1 行多く表示します。

この方法では、`partmap.png` と `master.png` が同じ大きさである必要があります。`cut.py` が `partmap size … differs from master` と表示したときは 2 枚の大きさが違い、`eyemap.py` は間違った位置を切り出します。

## 4. `rig.json` を書く：レイヤーを動かす

小克の `Pet\ui\characters\char-20261107\rig.json` をキャラクターフォルダにコピーします。第 1 節でコピーしたフォルダには、このファイルがすでに入っています。

**`parameters` は一文字も変えないでください。** うなずきと身ぶりの動きの数値（`Pet/src-tauri/src/cue/figure.json`）は、このパラメータ表に結びついています。各パラメータの id、範囲、デフォルト値、そしてその並び順です。完全に同じであれば、新しいキャラクターも小克と同じうなずきと身ぶりをします。少しでも変えると身ぶりはすべて無効になり、待機、まばたき、口の動き、カーソルを見る動きだけが残ります。

変えるのは回転軸です。つまり、小克の体の位置を、あなたのキャラクターの体の同じ位置に置き換えます。座標は `layers.json` の `canvas` 上のピクセル、つまり `master.png` のピクセルで、左上が (0, 0) です。カーソルの座標が表示される画像ビューアやお絵かきソフトなら何でも測れます。

| `rig.json` の位置 | 何か | 小克の値 |
| --- | --- | --- |
| `nodes` の `body` | 腰。体が揺れる中心 | `[510, 600]` |
| `nodes` の `skirt` | スカートが揺れる中心 | `[510, 590]` |
| `nodes` の `head` | 首。頭が回る中心 | `[507, 270]` |
| `nodes` の `armRight` | 画面左側の腕の肩 | `[385, 335]` |
| `nodes` の `armLeft` | 画面右側の腕の肩 | `[638, 335]` |
| `layers` の `back_hair` | 後ろ髪が揺れる支点。頭のてっぺん | `[512, 40]` |
| `layers` の `front_hair`、`hair_clip` | 前髪が揺れる支点 | `[505, 20]` |
| `layers` の `eye_white_image_left`、`iris_image_left`、`eye_lash_image_left` | 画面左側の目の中心 | `[462, 169]` |
| `layers` の `eye_white_image_right`、`iris_image_right`、`eye_lash_image_right` | 画面右側の目の中心 | `[557, 167.5]` |
| `layers` の `mouth_open` | 口の中心。口を開けるとき、ここから上下に広がる | `[508, 224]` |
| `layers` の `leg_image_left`、`leg_image_right` | 太ももの外側の上端。両足を閉じるときの回転軸 | `[352, 866]`、`[666, 862]` |
| `look` の `at` | 両目の間。カーソルを見るとき、ここから見る | `[508, 170]` |

目の中心には、`layers.py` が表示する `iris left: centre x,y` と `iris right: centre x,y` をそのまま使えます。

レイヤー名の left と right は画面上の左右です。ノード名はキャラクター自身から見た左右なので、`armRight` というノードには `arm_image_left`、つまり画面左側の腕がぶら下がっています。

各 `drive` に書くのは「このパラメータ 1 単位あたり、`x`／`y` ピクセル平行移動し、`rotate` 度回転し、`sx`／`sy` 拡大縮小する」という値です。腕は 1 単位が 1 度です。最初は変えなくてかまいません。デスクトップ上で動く様子を見てから調整してください。

`layers.py` が取り除いたレイヤーは、`rig.json` の `layers` からもその項目を削除します。削除しないと彼女は描画されず、原因は `rig.json rigs hair_clip, which layers.json does not have` と表示されます。

各レイヤーは 1 枚の画像で、平行移動、回転、拡大縮小しかできません。Live2D のように変形はしません。まばたきと口の開閉は 2 枚の画像の切り替えです。

## 5. `character.json` を書く

```json
{
  "name": "ハナ",
  "outfit": "制服",
  "persona": "あなたはユーザーのデスクトップの隅に住んでいます。話は短く、親しみやすく、日本語で答えます。",
  "greeting": "こんにちは、ハナです。",
  "voice": "voice.wav",
  "fillers": ["うーん……", "ちょっと考えますね"]
}
```

| 項目 | 必須 | 制限 | 使われる場所 |
| --- | --- | --- | --- |
| `name` | はい | 1 から 32 文字、改行不可 | 設定の一覧、会話ウィンドウの名札、会話モデルに渡す説明 |
| `persona` | はい | 1 から 2000 文字 | 会話モデルに渡すキャラクター説明 |
| `outfit` | いいえ | 1 から 16 文字、改行や角かっこは不可 | 設定の一覧にだけ「ハナ（制服）」のように表示され、同じキャラクターの別の衣装を見分けるのに使う |
| `greeting` | いいえ | 最大 200 文字、角かっこは不可 | マスコットの起動時と、彼女に切り替えたときに 1 回話す |
| `voice` | いいえ | `"voice.wav"` としか書けず、フォルダにそのファイルが実際に必要 | 彼女の声。第 7 節を参照 |
| `fillers` | いいえ | 最大 12 個、1 個につき 1 から 40 文字 | 答えを考えている間に話す口ぐせ。第 7 節を参照 |

知らない項目があると拒否されます。項目名を打ち間違えたときは、設定の一覧にどれが間違っているかがそのまま表示されます。黙って無視されることはありません。

## 6. 置いて、彼女に切り替える

1. フォルダ名がキャラクターの id になります。使えるのは英小文字、数字、`-`、`_` だけで、先頭は英字か数字、最大 48 文字です。内蔵キャラクターと同じ名前は使えません。
2. フォルダは `%USERPROFILE%\.vrpet\characters\<id>\` に置きます。設定の「角色」（キャラクター）タブにある「打開角色資料夾」（キャラクターフォルダを開く）で、この場所を直接開けます。
3. フォルダの最上位に `character.json`、`rig.json`、`layers.json`、そして `layers.json` に書かれているすべての PNG があることを確認します。
4. 「結束」（終了）でマスコットを閉じ、`Scripts\start_pet.ps1` をもう一度実行します。
5. 設定の「角色」（キャラクター）タブを開き、彼女の名前をクリックします。

マスコットは選んだキャラクターを覚えているので、次に起動したときも彼女のままです。

## 7. 彼女の声と口ぐせ

この節ではローカル音声を使います。ローカル音声をインストールしていなくてもキャラクターは使えますが、声は出ません。

**声。** 参考用の録音を `voice.wav` として保存してキャラクターフォルダに置き、`character.json` に `"voice": "voice.wav"` を加えてから、マスコットを再起動します。音声サービスはこの録音の声をまねします。書き起こしは不要です。

- 1 人の人のクリアな録音を使い、BGM や雑音が入っていないものにします。小克の参考録音は 22.7 秒です。
- 録音の音質も一緒にまねされます。電話のような音質の録音からは、電話のような声が合成されます。
- ファイルは最大 10 MB です。
- 使う権利のある声だけを使ってください。本人の同意なしに実在の人の声をまねしないでください。

**口ぐせ。** 彼女は答えを考えている間、まず口ぐせを 1 つ話します。`character.json` に `fillers` を書いたら、音声サービスが動いていて、キャラクターフォルダが所定の場所に置いてある状態で次を実行します。

```powershell
.venv\Scripts\python.exe Scripts\tts_engines\render_fillers.py "$env:USERPROFILE\.vrpet\characters\hana"
```

このスクリプトは彼女の声で各フレーズを 2 回ずつ合成し、よい方を残して `fillers.json` に書き出します。結果は音声認識でチェックしていないので、自分で一通り聞いて確認してください。

彼女に自分の声があるのに `fillers.json` がない場合、口ぐせは話しません。デフォルトの口ぐせは小克の声だからです。

## 8. 彼女が表示されない、見た目がおかしい

| 見えている状態 | 原因 | 対処 |
| --- | --- | --- |
| 設定の一覧で彼女の行がグレーになり、後ろに理由が書かれている | スキャン時のチェックに通らなかった | その理由に従って直し、マスコットを再起動する |
| 一覧に彼女がまったく出てこない | フォルダが `characters` の中にない、またはまだ再起動していない | 「打開角色資料夾」（キャラクターフォルダを開く）で場所を確認する |
| 彼女が描画されない | `rig.json` とレイヤーが合っていない | `%USERPROFILE%\.vrpet\logs\pet.log` の `SPIKE_REPORT` の行にある `"character"` を見る。`"error"` に原因が書かれている |
| うなずきや身ぶりをしない | `rig.json` の `parameters` が小克のものと違う | `pet.log` に `gestures: <id> bound by cue/figure.json` があれば、正しく結びついている |
| 文字は出るが声が出ない | 会話ウィンドウに理由が表示される | よくあるのは `character 'hana' has no voice.wav` |

グレーになるよくある原因：

- フォルダ名がルールに合っていない。たとえば大文字や空白が入っている。
- `character.json`、`rig.json`、`layers.json` のどれかがない。
- `character.json` が読み取れない。項目名を打ち間違えたときは、理由に `unknown field` と間違えた名前が含まれる。
- `voice` に `voice.wav` と書いてあるのに、フォルダにそのファイルがない。
- ファイルが大きすぎる。上限は PNG 1 枚 16 MB、JSON 1 つ 1 MB（`fillers.json` は 8 MB）、`voice.wav` 10 MB、フォルダ全体 200 MB。
- フォルダにショートカット（symlink または junction）がある。マスコットは安全のためショートカットをたどらず、キャラクター全体を読み込まない。

キャラクターフォルダは他の人が作ったものや、ネットからダウンロードしたものかもしれません。そのためマスコットはフォルダの最上位にある PNG、JSON、WAV だけを読み、どのファイルもサイズを確認します。「個性」（性格）の文章は、あなたが選んだ会話モデルに渡されます。彼女自身にはツールが一切なく、あなたのファイルには触れられません。

## 9. 画面テーマ

会話ウィンドウの色、角の丸み、2 つの小さな画像も変えられます。やり方はキャラクターと同じで、1 つのテーマは `theme.json` が入った 1 つのフォルダです。内蔵テーマは「紙本」（ペーパー、`paper`）と「夜色」（ナイト、`night`）の 2 つです。

```json
{
  "name": "マイテーマ",
  "colors": {
    "accent": "#d97757",
    "paper": "#f3f2ef",
    "ink": "#2b2b2b",
    "border": "#cfc8bc",
    "controls": "#f3f2ef"
  },
  "radius": 18,
  "icon": "icon.svg",
  "paper_texture": "paper.svg"
}
```

| 項目 | 必須 | 制限 | 使われる場所 |
| --- | --- | --- | --- |
| `name` | はい | 1 から 32 文字 | 設定の「外觀」（外観）タブ |
| `colors.accent` | はい | `#rrggbb` | マウスを重ねたときと入力中の枠線。彼女の名前の色は accent を ink の方へ 40% 寄せた色 |
| `colors.paper` | はい | `#rrggbb` | 会話ウィンドウ、選択肢、会話履歴、設定ウィンドウの背景色 |
| `colors.ink` | はい | `#rrggbb` | 文字の色 |
| `colors.border` | はい | `#rrggbb` | すべての枠線 |
| `colors.controls` | はい | `#rrggbb` | ボタン列、入力欄、マイクボタンと、設定ウィンドウのボタンと入力欄の背景色 |
| `radius` | はい | 0 から 28 の整数、単位は px | 会話ウィンドウと設定ウィンドウの角の丸み |
| `icon` | いいえ | フォルダ内の `.svg` または `.png` 1 つ | 会話ウィンドウで彼女の名前の横に出る小さなアイコン |
| `paper_texture` | いいえ | フォルダ内の `.svg` または `.png` 1 つ | 背景色の上に敷くテクスチャ |

1. フォルダ名のルールはキャラクターと同じです。`%USERPROFILE%\.vrpet\themes\<id>\` に置きます。設定の「外觀」（外観）タブにある「打開主題資料夾」（テーマフォルダを開く）でこの場所が開きます。
2. 設定ウィンドウに戻ると、新しいテーマが一覧に出ています。マスコットを再起動する必要はありません。クリックすると切り替わります。

制限：

- 画像のファイル名に使えるのは英小文字、数字、`_`、`.`、`-` だけです。
- `theme.json` は最大 64 KB、画像は 1 枚最大 2 MB、フォルダ全体は最大 8 MB です。
- テーマに CSS は入れられません。変えられるのは上の 5 つの色、角の丸み、2 つの画像だけです。
- 問題のあるテーマはグレーになり、理由が表示されます。選んでいるテーマが壊れたときは、マスコットはいったん「紙本」（ペーパー）を使い、直れば元に戻ります。

## 10. キャラクターをインストールパッケージに入れる

この節は repo 自体を変更する人向けです。キャラクターフォルダを `Pet/ui/characters/<id>/` に置き、`Pet/ui/characters/index.json` の `characters` に id を追加してから、マスコットをビルドし直します。テーマの場合は `Pet/ui/themes/<id>/` と `Pet/ui/themes/index.json` です。変更したら `Scripts\run_pet_selftests.ps1` を 1 回実行してください。
